Documentation defects found while running examples from README.md
---------------------------------------------------------------

1) add_product: incorrect parameter names and invalid ranges
   - README example:
       pid = mgr.add_product(title="Laptop", cost=-1000, amount=-5, labels=["electronics", "featured"])
   - Implementation expects: add_product(name: str, price: float, stock: int = 0, tags: Optional[List[str]] = None)
   - Behavior: negative price and stock raise ValueError in the library. The wrong parameter names produce TypeError.
   - Evidence:
      TypeError: ProductManager.add_product() got an unexpected keyword argument 'title'
       (Captured from test_files/test_readme_example.py runtime output.)

2) update_stock vs modify_stock
   - README calls mgr.modify_stock(pid, new_value=10)
   - Implementation has update_stock(product_id: str, delta: int) which changes the stock by delta
   - Evidence:
      AttributeError: 'ProductManager' object has no attribute 'modify_stock'

3) list_products: wrong param name and logic
   - README uses mgr.list_products(available_only=True)
   - Implementation uses include_out_of_stock: bool = True; to list only available items use include_out_of_stock=False
   - Evidence:
      TypeError: ProductManager.list_products() got an unexpected keyword argument 'available_only'

4) get_total_value vs calculate_total_value
   - README uses mgr.calculate_total_value()
   - Implementation has get_total_value() returning a rounded float
   - Evidence:
      AttributeError: 'ProductManager' object has no attribute 'calculate_total_value'

5) export_inventory_to_csv vs export_inventory
   - README uses mgr.export_inventory_to_csv("inventory.csv")
   - Implementation provides export_inventory(filepath: str) that writes JSON
   - Evidence:
      AttributeError: 'ProductManager' object has no attribute 'export_inventory_to_csv'. Did you mean: 'export_inventory'?

6) get_activity_log: missing argument docs
   - README uses mgr.get_activity_log() without docs
   - Implementation requires an integer limit parameter defaulting to 10; method returns last 'limit' entries
   - Evidence: the method signature: get_activity_log(self, limit: int = 10) -> List[str]

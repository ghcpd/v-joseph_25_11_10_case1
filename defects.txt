Documentation defects identified while verifying examples in README.md

1) Incorrect parameter names in README examples (MISMATCH)
 - README usage: mgr.add_product(title="Laptop", cost=-1000, amount=-5, labels=[...])
 - Actual function signature: add_product(name: str, price: float, stock: int = 0, tags: Optional[List[str]] = None)
 - Evidence: running this example will raise TypeError: add_product() got an unexpected keyword argument 'title'

  Sample trace (TypeError):
  TypeError: ProductManager.add_product() got an unexpected keyword argument 'title'

2) Invalid ranges shown in README (INVALID INPUT)
 - README uses negative price and negative stock; actual code raises ValueError for negative price or stock.
 - Evidence: add_product(name="Laptop", price=-1000.0, stock=-5) raises ValueError: Price must be positive.

  Sample trace (ValueError):
  ValueError: Price must be positive.

3) Incorrect function name to update stock (MISMATCH)
 - README usage: mgr.modify_stock(pid, new_value=10)
 - Actual function name: update_stock(product_id: str, delta: int)
 - Evidence: modify_stock attribute missing -> AttributeError

  Sample trace (AttributeError):
  AttributeError: 'ProductManager' object has no attribute 'modify_stock'

4) list_products usage - param name mismatch and semantics (MISMATCH)
 - README uses available_only=True, which does not exist. The correct param is include_out_of_stock: bool = True.
 - To list available only, set include_out_of_stock=False.

5) get_total_value method name outdated (OUTDATED)
 - README uses calculate_total_value(), actual method is get_total_value()

6) Export format and function name mismatch (MISMATCH/OUTDATED)
 - README uses export_inventory_to_csv("inventory.csv"), actual method is export_inventory(filepath: str) and writes JSON.

7) Password-protected export documented but not implemented (OUTDATED / MISSING FEATURE)
 - README mentions password-protected export (export_inventory(password="mypwd")) but current implementation has no such parameter.

8) Activity log method docs: missing a documented 'limit' param (MISSING DOCS)
 - README uses get_activity_log() but does not document that you can pass a limit: get_activity_log(limit: int = 10)

9) Currency validation and supported currencies incorrectly documented (MISSING/OUTDATED)
 - README lists supported currency values but ProductManager does not validate currency or limit to that set. Document that currency is a free-form string.

10) Tag filtering not documented properly (MISSING DOCS)
 - README mentions tag-filtering but does not show the correct param name: tag_filter

Summary:
 - Most examples use incorrect parameter names or outdated method names. Tests and corrected examples provided in corrected_readme.md.
